BASE_DIR - обязательное поле, содержит до папки, предназначенной для хранения комиксов, в ней будут выполняться все комманды.

Подпапки для комикса - при создании комикса в будут созданы дополнительные папки; предположительное назначение - для ярлыков.

Подпапки для отдельной части - при добавлении новой части в ней будут созданы дополнительные папки. Обязательные папки будут созданы в любом случае.

Минимальное количество символов в номере части - при создании новой части ее номер - имя папки - будет дополнен до указанного количества символов нулями.

Функции:

Create comics - создает папку с указанным именем в папке BASE_DIR, после создает в ней подпапки.

Create new chapter - создает нумерованную папку в папке выбранного комикса, после создает в ней подпапки.

Extract image - в папке Original части комикса вы размещаете скачанную страницу и прилагающиеся к ней файлы, функция изучит строение страницы, получит имена файлов страниц комикса, переместит и переименует файлы страниц в папку Original.
