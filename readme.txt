Файл .env - файл настроек, его можно изменить в Блокноте.
Значения файла .env:

BASE_DIR - обязательное поле, абсолютный путь к папке (пример: C:\Users), 
все папки в ней 
будут добавлены в меню выбора комикса.

ORIGINAL - необязательное поле, имя папки, в которой хранитится файл комикса и его файлы.
Если поле не заполнено или некорректно, будет использоваться имя "Original".

ADDITIONAL_FOLDERS - список имен для дополнительных папок, разделенных запятыми.
Некорректные имена будут проигнорированы.

При создании комикса и добавлении части папки будут добавлены подпапки
с соответствующими именами. Недопустимые имена - заканчивающиеся на символ . или
содержащие символы / \ | : < > "  ? * (запрещенные символы Windows).

LENGTH_NUMBER - минимальное количество символов в номере части (не больше десяти
знаков), при создании новой части ее номер - имя папки - будет дополнен
до указанного количества символов нулями. Необязательное, по умолчанию - 2.

DELETE - удаление файлов комикса после извлечения изображений, число 0 - ничего не делать,
1 (любое положительное число) - файлы будут помещены в Корзину. Некорректные значения
- ничего не делать.

--------------------------------------------------------------------------------

Часть комикса - любая папка, начинающая с числа.
Подпапка - папки с именами, указанными в ORIGINAL или ADDITIONAL_FOLDERS

Каждый раз, когда предлагается выбор, действие можно отменить, нажав Enter.
Нажатие Enter при выборе действия приведет к завершению работы.

Функции:

Создать комикс - создает папку с указанным именем в папке BASE_DIR,
создает в ней подпапки.

Добавить часть - создает нумерованную папку с подпапками
в папке выбранного комикса.

Извлечь изображения - в части комикса, в папке ORIGINAL программа ищет файл сайта
и его папку (ее имя совпадает с именем файла и оканчивается на "_files"), после
чего копирует изображения в папку ORIGINAL части или в ней же создает файл
"Union.png", вертикально склеив изображения. Повторяется со всеми частями комикса.

Создать ярлыки - создает ярлыки файлов в подпапках частей в соответствующей
подпапке комикса; если в меню выбран вариант 'Для файлов папки', то в папке комикса
будет создана папка 'Разное', где будут размещены ярлыки файлов части комикса.
Имя ярлыка - "<номер части>_<имя файла>".
