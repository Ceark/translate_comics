Файл .env - файл настроек, его можно изменить в Блокноте.

Часть комикса - любая папка, начинающая с числа.

Подпапка - папки с именами, указанными в ORIGINAL или ADDITIONAL_FOLDERS

--------------------------------------------------------------------------------

При запуске программы, если рядом с ней или в папках на пути к ней нет файла .env,
программа создаст рядом с собой файл со всеми значениями и предложит ввести путь
к папке, в которой будет вестись работа. Значения файла .env:

BASE_DIR - обязательное поле, абсолютный путь к папке (пример: C:\Users), 
все папки в ней будут добавлены в меню выбора комикса.

ORIGINAL - необязательное поле, имя папки, в которой хранится файл комикса и его файлы,
после экстракции - изображения. По умолчанию - Original.

ADDITIONAL_FOLDERS - необязательное поле, список имен для дополнительных папок,
разделенных запятыми (пример: Перевод, Тексты, Редактор). По умолчанию - пустое.

При создании комикса и добавлении части в них будут добавлены подпапки.
Недопустимые имена - заканчивающиеся на символ . или те, в которых есть запрещенные
символы Windows: / \ | : < > "  ? * () - будут проигнорированы.

LENGTH_NUMBER - необязательное поле, минимальное количество символов в номере части
(не больше десяти, пример: 3), при создании новой части ее номер будет дополнен
до указанного количества символов нулями. По умолчанию - 2.

DELETE - удаление файлов комикса после извлечения изображений, число 0 - ничего не делать,
1 (любое положительное число) - файлы будут помещены в Корзину. По умолчанию - 0.

--------------------------------------------------------------------------------

Каждый раз, когда предлагается выбор, действие можно отменить, нажав Enter.
Нажатие Enter при выборе действия - завершению работы.

Функции:

Создать комикс - создает папку с указанным именем в папке BASE_DIR.

Добавить часть - создает нумерованную часть в выбранном комиксе.

Извлечь изображения - в части комикса, в папке ORIGINAL программа ищет файл сайта
и его папку (ее имя совпадает с именем файла и оканчивается на "_files"), после
чего копирует изображения в папку ORIGINAL части или в ней же создает файл
"Union.png", вертикально склеив изображения. Повторяется со всеми частями комикса.

Создать ярлыки - для файлов из подпапок частей создает ярлыки в соответствующей
подпапке комикса; если в меню выбран вариант 'Для файлов папки', то ярлыки будут
созданы для файлов в папке части, в папке комикса для ярлыков будет создана
папка "Разное". Имя ярлыка - "<номер части>_<имя файла>"
